# i9 "Reading one you have never seen": plain-English edit

I rewrote 78 sentences in i9.lesson.verified.json. Most were long sentences joined with "and", "so", a colon or a
semicolon. Each is now split into short sentences, one idea each, with the point first. The edits cover:
- explain: the four steps, the sources paragraph, the state paragraph, the hoist example and the key rule. I added
  paragraph breaks so each step starts its own paragraph.
- the analogy (text and breaks) and the practice, including the worked example's State and Trace lines.
- the interactive's brief, whatAmILookingAt and ignores: the sheets, the rules, the cross-references, the screen
  words, read sentences, hints and whys. The brief keeps its "The one thing you should see is ... when you ..." form.

"A short lesson in fourteen small screens" became "Fourteen small screens follow", so the text no longer talks about
the lesson itself. The redundant "Screen by screen." heading went. A token check confirmed that every number, unit,
tag (-Q8, -K11, R1 and the rest), N.C./N.O. mark, [[term]] and [^n] citation is unchanged. A few tags were added where
"it" or "its" was unclear: "-K12's contact in path 3", "With -Y11 energised". Sources, ids, numbers, controls and
structure are untouched. The lesson has no predict, say or checks.

whatAmILookingAt has a 12,000-character limit, with 15% slack (13,800). It was at 13,797 before the edit. So I kept the
splits and dropped filler words to stay inside it: it now stands at 13,784. A few splits that cost too many characters
were left as they were: "Stop button -S10 and overload contact -F11, both normally closed, ..." and screen 14's set-up.

i9.lesson.final.json got the same rewrite wherever it holds the same text. It still has its pre-fact-check wording in
a few places: no "usually" or "may" in the explain's source and state lines, "running source", "The sources step
finds it", no "running or not" in the practice, and "Real ones can let a little through" in ignores. Those places
kept their own facts and were reworded the same way.

The SHOW screens' words run from 35 to 41 words, well under 90. The validator passes on both files with `--final`.
