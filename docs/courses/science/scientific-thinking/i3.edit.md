   - Before: "Its distance runs from the pivot to the string the weight hangs on, at right angles to the string.[^2] Weights hang straight down, so on a level bar it is the distance along the bar from the pivot, not from the bar's end."
   - After: "Its distance runs from the pivot to the weight's string. It is measured at right angles to the string.[^2] Weights hang straight down. So on a level bar, it is the distance along the bar from the pivot. It is not measured from the bar's end."
