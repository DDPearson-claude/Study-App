So at the mesh the teeth of both gears move the same way, and the two gears turn opposite ways.[^1] Say the driver turns clockwise, with the next gear on its right. The driver's right-hand teeth move down. They push the next gear's left-hand teeth down too, and that turns it anticlockwise.\n\nSo each mesh between outside teeth flips the direction. Along a line of such gears, each meshing the next, the directions alternate. An odd number of gears in a line turns the last one the driver's way. An even number turns it the other way. A gear's size changes how fast it turns, not which way. One gear set between two others makes them turn the same way. It is called an [[idler gear]].
