The supply's voltage holds the flux, and the primary cancels whatever ampere-turns the load adds. So the flux barely changes from no load to full, and nor does this [[iron loss]]. The windings are different. They are copper with resistance, so they waste I²R. Double the current and this [[copper loss]] goes up four times. So the iron loss is there whenever the transformer is energised, whatever the load, while the copper loss grows with the square of the load.[^1] Some flux also leaks round each winding without threading the other.
