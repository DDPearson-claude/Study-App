## Five before-and-after examples

1. **Explain, the four conditions**
   - Before: "Each can be fooled, though. Trust a reading only when four things hold. The cell is rested, the reading is corrected for temperature, the level is right and the acid is mixed."
   - After: "But each gauge can be fooled. Trust a reading only when four things hold. The cell has rested. The reading is corrected for temperature. The level is right. The acid is mixed."

2. **Explain, the temperature rule**
   - Before: "Makers give a correction to a set temperature, often 25 °C. One maker's rule adds one point for every 1.67 °C above 25 °C.[^2] Below 25 °C, take points off the same way."
   - After: "Makers correct the reading to a set temperature, often 25 °C. One such rule adds one point for every 1.67 °C above 25 °C.[^2] Below 25 °C, it takes points off the same way."

3. **Explain, the rested voltage**
   - Before: "By one common guide, a cell resting at 2.10 V at room temperature is about 90 per cent charged.[^1] Guides differ a little, and weaker acid, like this stationary cell's, rests lower, so use the maker's figures."
   - After: "As a rough guide, a cell resting at 2.10 V at room temperature is about 90 per cent charged.[^1] The figures vary a little from guide to guide. Weaker acid, like this stationary cell's, rests lower, so use the maker's figures."

4. **Interactive, screen 10**
   - Before: "10 asks which check failed on a cell that rested a day, is corrected and level, reads high on the voltmeter yet runs out early."
   - After: "10 shows a cell that has rested a day, is corrected and is level. It reads high on the voltmeter yet runs out early. Which check failed?"

5. **Practice, the worked example**
   - Before: "25 − 20 = 5 °C below, and 5 ÷ 1.67 is about 3 points. Corrected: 1.228 − 0.003 = 1.225, full."
   - After: "That is 25 − 20 = 5 °C below the set temperature. So the correction is 5 ÷ 1.67, about 3 points. The corrected reading is 1.228 − 0.003 = 1.225, which is full."
