# i6 "Strings: the weakest cell sets the pace": plain-English edit

The facts, numbers, units, formulas and [^n] citations have not changed. A script compared the numbers, units, [^n] marks and [[term]] marks in every edited field, before and after the edit. They all match. The sources, ids and structure were not touched.

Both files now hold the same text, so `i6.lesson.verified.json` and `i6.lesson.final.json` are byte-identical. The final file therefore also picks up the fact-checked wording that only the verified file had before:
- 2.23 V a cell is "one maker's" float, for its vented cells at 20 °C
- overcharge "helps corrode" the positive grid
- parallel strings share the load inversely to resistance "at equal voltage", in explain and in the rule of thumb
- the string on the short cable "is run down further"
- the tanks also count charge in as equal to charge out
- read specific gravity "on a vented cell"

`validate.mjs lesson ... --final` passes on both files.

132 sentences are new or rewritten. They are spread across explain, analogy (text and breaks), practice, interactive.brief, interactive.whatAmILookingAt and interactive.ignores. Most changes split a long sentence so that each one carries one idea. Others lead with the point, or turn a passive line into an active one. Explain is now in shorter paragraphs: discharge, reversal, charge, float, the band, and parallel strings. The lesson has no `checks`, `say` or `predict` text. `interactive.brief` keeps the fixed form "The one thing you should see is ___ when you ___."
