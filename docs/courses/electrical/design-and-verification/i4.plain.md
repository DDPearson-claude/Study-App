## 1. What it is for (page, screen 2)
- Before: Some circuits, supplying rectifiers, variable-speed motor drives or fluorescent lighting banks, draw currents that are not sinusoidal (your slides p.33), and then the circuit may need designing on the neutral current, not the line current (p.34). The On-Site Guide asks the same of a discharge-lighting final circuit: it must carry its harmonic currents as well as the lamps' current (OSG p.136).
- After: But circuits supplying rectifiers, variable-speed motor drives or fluorescent lighting banks draw currents that are not sinusoidal. Then the circuit may need designing on the neutral current, not the line current. A discharge-lighting final circuit must carry its harmonic currents as well as the lamps' current.

## 2. The red "If it is skipped" note (page, screen 2)
- Before: the neutral current gives rise to additional heating of the cables (IET Wiring Matters 23), and it comes without any matching fall in the line currents (NICEIC, Regulation 523.6.3), so a cable sized on the line current alone does not allow for it.
- After: the neutral current adds heat to the cables. The line currents do not fall to make up for it. So a cable sized on the line current alone does not allow for that heat.

## 3. Which current, which factor (page, screen 4)
- Before: The current tables are worked for three loaded conductors (the Schneider guide). A neutral carrying harmonic current is a fourth loaded conductor in the same cable or conduit: BS 7671 counts it as one where the third harmonic and its multiples pass 15% (Regulation 523.6.1, as NICEIC words it). A neutral carrying only the lines' imbalance is offset by less heat in a line; harmonic current gets no such offset (NICEIC).
- After: The current tables are worked for three loaded conductors. A neutral carrying harmonic current is a fourth loaded conductor in the same cable. BS 7671 Regulation 523.6.1 counts it as one once the third harmonic and its multiples pass 15%. A neutral carrying only the lines' imbalance is offset by less heat in a line. Harmonic current gets no such offset.

## 4. Table 4Aa, row 3 (page, screen 4)
- Before: Row 3, 33 to 45%: the neutral is now the larger, so the cable is selected on the neutral current (the Schneider guide; the IET's answer reads "exceeding 33 %"), still with 0.86.
- After: Row 3, 33 to 45%: the neutral is now the larger, so the cable is selected on the neutral current. The factor is still 0.86. At exactly 33%, the line still sets the cable.
