   "now": "[[Integrating]] is differentiating run backwards: you are given a rate and asked for the rule it came from.[^3] You already know the forward direction. The power rule takes x³ to 3x², so the question \"whose derivative is 3x²?\" has the answer x³. To answer such questions without guessing, undo the power rule's two steps in the opposite order.[^4] Forwards, you bring the power to the front, then take one off the power. Backwards, you add one to the power, then divide by the new power,[^4] so xⁿ becomes xⁿ⁺¹ ÷ (n + 1). For x², add one to get x³, then divide by 3 to get x³ ÷ 3. Check it by differentiating: the power rule gives 3x² ÷ 3 = x², what you started with. The same happens for any power: differentiating xⁿ⁺¹ ÷ (n + 1) brings the n + 1 to the front and takes one off the power, giving (n + 1)xⁿ ÷ (n + 1) = xⁿ, so the two steps cancel. A number in front carries through and a sum is done term by term, because differentiating works that way forwards,[^5][^6] so 6x² + 4x + 5 becomes 6 × x³ ÷ 3 + 4 × x² ÷ 2 + 5x = 2x³ + 2x² + 5x. The plain 5 comes from 5x, whose slope is 5 everywhere. One power will not go: −1, which is 1 ÷ x, because adding one gives a power of 0 and you cannot divide by 0.[^1] Textbooks add that its reverse is a different function, the natural logarithm, which this course does not use.\n\nDifferentiating loses something, and you have to put it back. A plain number does not change as x changes, so its derivative is zero, and x² + 5, x² and x² − 3 all differentiate to the same 2x. On the picture, adding a number lifts every point of the curve by the same amount. Take any chord, as in lesson 1: both its ends are lifted by c, so its rise is unchanged, and so is its slope. That holds for chords however short, so the tangents keep their slopes too, and the curve slides up or down without its steepness changing anywhere: move the slider for c and the tangent at x = 2 keeps its slope of 4 while its height changes. So working back from 2x cannot tell you which of those curves you came from, and the full answer is the whole family, x² + c, where c stands for any number.[^7] That c is the [[constant of integration]]. The answer is written ∫ 2x dx = x² + c, the [[integral]] of 2x: the ∫ sign says integrate, and dx says x is the letter that changes. The constant is easy to get wrong: on one 2023 Advanced Higher question, Scottish examiners reported that many candidates made basic errors in applying a formula approach or in dealing with the constant of integration.[^2]\n\nTo pick one curve out of the family, you need one value you know: where the thing started, or where it was at some moment.[^8][^9] Remember the charge rule q = 0.5t² from Rates on the job, whose current was t amps? Run it backwards. Say a capacitor charges with a current that rises steadily, i = t amps after t seconds. Current is the rate charge flows, i = dq/dt, so the charge is the integral of the current: q = ∫ t dt = t² ÷ 2 + c = 0.5t² + c coulombs. Say it already held 3 C at 0 s. Put t = 0 in: 0.5 × 0 + c = 3, so c = 3 and q = 0.5t² + 3. At 4 s it holds 0.5 × 16 + 3 = 8 + 3 = 11 C. Leave the c out and q = 0.5t² says the capacitor held 0 C at the start, not the 3 C it did, and 8 C at 4 s, short by the same 3 C all the way along. Check both halves: differentiating 0.5t² + 3 gives t, the current, and at 0 s it gives 3 C, the start. The value you know need not be at the start: told instead that it held 5 C at 2 s, you would get 0.5 × 4 + c = 5, so c = 3 again, the same curve. **Integrating undoes differentiating:[^3] add one to the power, then divide by the new power, for any power but −1;[^4][^1] add + c, because a constant differentiates to zero;[^7] and fix c from a value you are given.[^8]**"
