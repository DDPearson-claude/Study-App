    "text": "When one equation tells you what y equals, you can write that in place of y in the other equation. That leaves one equation with one unknown,[^1] which you already know how to solve, and the first equation then gives y. Take lesson 1's pair, y = 2x + 1 and x + y = 7. Ride the point along line 1. Wherever it is, its y is 2x + 1, because that is the rule line 1 draws. So for that point, the x + y of equation 2 is x + (2x + 1). The two bars show that total beside 7, and they match only where the point reaches line 2, because that is the one point on line 1 that fits x + y = 7 as well. At the crossing point the y is the same in both equations, so the y in equation 2 is the very y line 1 gives, 2x + 1.\n\nSo write it in. Put the expression for y into the other equation,[^2] with a bracket round it: x + (2x + 1) = 7. Now only x is left. Collect like terms, 3x + 1 = 7, take 1 from both sides, 3x = 6, and x = 2. That is only half the pair, so put x = 2 back into y = 2x + 1 to get y = 5. Check in both: 2 × 2 + 1 = 5 and 2 + 5 = 7, so (2, 5) is the crossing point. Swapping an expression in for a letter like this is called [[substitution]]. It is exact, so lesson 1's crossing that fell between the tenths comes out too. With x + y = 5 you get 3x + 1 = 5, so x = 4/3 and y = 2 × 4/3 + 1 = 11/3, and 4/3 + 11/3 = 15/3 = 5.\n\nWhen neither equation starts \"y =\", make y the subject of one first. 2x + y = 11 becomes y = 11 − 2x. Swapped into 3x − y = 9, it gives 3x − (11 − 2x) = 9. The minus takes away all of the bracket, so both signs inside change: 3x − 11 + 2x = 9. Then 5x = 20, x = 4 and y = 11 − 8 = 3. Check: 8 + 3 = 11 and 12 − 3 = 9.\n\nSometimes the x's cancel. With y = 2x + 1 and y − 2x = 4, swapping in gives (2x + 1) − 2x = 4, which is 1 = 4. That is false whatever x is, so no pair fits both: the lines are parallel and there is no solution.[^3] Ride line 1 and the left bar stays at 1, never reaching 4. With y − 2x = 1 instead, you get 1 = 1, true whatever x is, because line 2 is line 1 written another way, and there are endless solutions.[^5] Textbooks add that a pair of equations with no solution is called inconsistent. **Substitution puts what one equation says y equals into the other, which leaves one equation in one unknown;[^1] solve it, put the answer back for y, and check the pair in both.**"

    "text": "- Pick the equation that says what y (or x) equals. If neither does, rearrange one, doing the same to both sides.\n- Write that expression in place of the letter in the other equation, inside a bracket.\n- Expand the bracket, minding a minus or a number in front of it, and solve for the one unknown left.\n- Put that value back into the first equation to get the other unknown.\n- Check the pair in both of the original equations.\n- If the letter vanishes, read what is left. A false line such as 1 = 4 means no solution. A true line such as 1 = 1 means the equations are the same line, and every point on it is a solution.\n\n**Rule of thumb:** Swap in with a bracket, and do not stop at x.\n\n**Worked example:** y = 3x − 2 and 2x + y = 13. Swap in: 2x + (3x − 2) = 13. Collect like terms: 5x − 2 = 13, so 5x = 15 and x = 3. Put it back: y = 3 × 3 − 2 = 7. Check: 3 × 3 − 2 = 7 and 2 × 3 + 7 = 13, both true, so x = 3 and y = 7.\n\n**Common mistakes**\n- Changing only the first sign after a minus. 4x − (7 − 2x) is 4x − 7 + 2x, not 4x − 7 − 2x.\n- Multiplying only the first term in the bracket. x + 2(x − 2) is x + 2x − 4, not x + 2x − 2.\n- Rearranging with the wrong sign. 2x + y = 7 gives y = 7 − 2x, not y = 2x − 7.\n- Stopping at x. The answer is a pair, so put x back for y.\n- Checking in only one equation. (6, 1) fits x + 2y = 8, but not y = x − 2, as 6 − 2 = 4.\n- Reading 1 = 1 as x = 1. No x is left, so it says every x works.\n- Taking the numbers in the equations as the answer. y = 3x + 2 and y = 3x − 4 have no solution, and (3, 2) fits neither: 3 × 3 + 2 = 11."
