## The explanation Dan reads after playing (use the same words for the same things)
A letter stands for a number you do not know yet, so x is a number and 3x means 3 lots of it. Adding 3x and 2x is counting those lots, just as 3 sevens and 2 sevens make 5 sevens. Picture x as a bar whose length is the number. 3x is three bars end to end and 2x is two more, so together they are five bars, 5x. Change x and every bar changes with it, so the two rows still line up, which is why 3x + 2x = 5x whatever x is. Teachers disagree about the picture. A Bitesize video uses apples, while NCETM says the apples picture should be avoided, because a letter stands for a number, not an object, and treats it as counting lots of a number, as with sevens. This lesson uses bars, because x stands for a number.

Each part joined on by + or − is a term, and the sign in front of it belongs to it, even a minus at the very start. Terms with the same letters, each raised to the same power, like 3x and 2x, are like terms, and plain numbers are all like terms too. Only like terms can be added or taken away into one term. So 3x + 4 is already finished. 7x is 3x and 4x more, so it matches 3x + 4 only when 4x is 4, which is when x is 1. At x = 3, 3x + 4 makes 13 but 7x makes 21. A lone x is 1x, so 7x − 2x + 3 − x is 7 − 2 − 1 = 4 lots of x, plus 3, which is 4x + 3.

## The house kit (complete API reference)
You write the BODY of one page: HTML, an optional `<style>`, then one inline `<script>` ending

### The pipeline
Controls register themselves; their values form `params` = `{id: value}`.
```
K.model(fn)        fn(params) -> outputs {name: number | string}. Pure: no DOM, no lists or objects.
K.update(fn)       fn(params, outputs): draw everything here. More than one is allowed.
K.at(over)         -> outputs of the model at those params (others take each control's starting value)
K.check(label, fn, {source?})   fn() must return exactly true
K.ready()          call once, last: draws the opening state and runs the checks
K.complete()       at the lesson's end
K.params()  K.outputs()  K.refresh()   (refresh reruns the pipeline after you change your own state)
```
A readout whose id is an output key updates itself.

  K.check('A seconds pendulum (2 s per swing) is 0.994 m long', () => K.near(period(0.994), 2, 0.002),
    { source: 'https://en.wikipedia.org/wiki/Seconds_pendulum' });
  K.check('Four times the length doubles the period', () => K.near(K.at({ L: 2 }).T / K.at({ L: 0.5 }).T, 2, 1e-9));

  function pairs(by) {
