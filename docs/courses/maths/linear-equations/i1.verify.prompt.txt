Later ideas in the course (every claim must stay true after Dan has learned each of them):
- i2 Expanding brackets — Multiply every term inside the bracket, so 3(x + 5) = 3x + 15 and R₀(1 + αΔT) = R₀ + R₀αΔT, and a minus in front changes every sign.
- i3 Factorising — Factorising is expanding in reverse, taking out the shared factor: 6x + 15 = 3(2x + 5) and IR₁ + IR₂ + IR₃ = I(R₁ + R₂ + R₃).
