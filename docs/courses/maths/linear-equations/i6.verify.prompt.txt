  "text": "A job in words becomes an equation when you write what one part is and then how many parts there are, so a job made of identical two-part pieces gets a bracket. Say it in one sentence first:[^3] two cable runs, each x metres plus a 3 m tail, use 40 m in all. One run is x + 3, and the bracket keeps that run together, so two runs are 2(x + 3), and 2(x + 3) = 40. Writing 2x + 3 would count the tail once, though each run has its own. Undo it as in Equations with brackets: 40 ÷ 2 = 20, then 20 − 3 = 17, so x = 17. Put it back in to check:[^4] 2(17 + 3) = 2 × 20 = 40. An invoice works the same way. Two jobs, each a £60 call-out plus h hours at £40 an hour, come to £360, so 2(60 + 40h) = 360. Halve it to £180 for one job, take off the £60 call-out to leave £120, and £120 ÷ £40 is 3 hours.\n\nA formula with a bracket is undone in the same way.
