    "text": "A [[differential equation]] is a rule that gives how fast something changes from the thing itself. So its answer is not a number. It is a whole curve, the value at every moment. You have used a rate already. i = C dv/dt ties a capacitor's current to how fast its voltage changes. Cooling is a rate too. Newton's law of cooling says a liquid cools at a rate proportional to the difference between its temperature and the room's.[^1] Textbooks add that a small hot part in still air cools in about the same way. Write T for the part's temperature in °C and t for the time in minutes. The rule is dT/dt = −k(T − T_room). Here k says how quickly this part sheds heat, say 0.1 per minute. The minus sign makes it fall when it is above the room. dT/dt is a rate in °C a minute, not an amount of change. At 80 °C in a 20 °C room the gap is 60 °C, so the part is falling at 0.1 × 60 = 6 °C a minute. Textbooks call this a first-order equation, because the highest rate in it is dT/dt itself.\n\nAt every time and temperature, the rule gives the slope a solution curve must have there.[^2] Draw that slope as a short arrow at each point and you have a [[slope field]]. Here the slope depends only on the gap, so every arrow at one height matches. They point steeply down when the part is hot, flatter near the room, flat at 20 °C, and up below it. At 50 °C the gap is 30 °C, so the slope is −3 °C a minute. A solution is a curve that follows the arrows everywhere. Start at 80 °C and the curve falls steeply, then levels off towards the room. It levels off because the gap shrinks as the part cools, and the rate shrinks with the gap. A start at 50 °C gives a different curve under the same arrows. So the rule fixes the shape, and a starting value picks one curve, as a start fixed the + c in Calculus fundamentals.\n\nAt 20 °C the gap is zero, so the rate is zero. In this rule, a part that starts at room temperature stays there. The flat line T = 20 °C is a solution, a [[steady state]]. It is a curve that never changes, not just a number. To check a candidate, compare its slope with the rule's at every point. A straight line from 80 °C falling 6 °C a minute matches at the start. At 50 °C it still falls 6, while the rule wants 3, so it is not a solution. A rule can depend on time instead. dy/dt = 2t has flat arrows all down t = 0. Yet a flat line is not a solution, because at t = 2 the rule wants a slope of 4. The parabolas y = t² + c are solutions, because the slope of t² + c is 2t at every t. A coil's current settling and a circuit ringing are both curves set by rules like these, so reading the arrows is where telling them apart starts. Newton's rule is a simplified model, and a very hot part cools faster than it says.\n\n**A differential equation gives the slope at every point from the quantity itself,[^2] so its solution is a whole curve that matches that slope everywhere, and a starting value picks which curve.**"
