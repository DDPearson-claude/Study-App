   "now": "- Write each equation as a row: x, y and z in columns 1 to 3, the constant last. Put a 0 for a missing letter.\n- Use row 1 to clear column 1 in rows 2 and 3: add a multiple of row 1 to each.\n- Use the new row 2 to clear column 2 in row 3. Row 1 would put a number back in column 1.\n- If the row you clear with has a 0 in that column, first swap it with a lower row that does not.\n- Read the rows. Any row of 0 = a number other than 0 means no answer. With no such row, a row of 0 = 0 means infinitely many. Otherwise the bottom row gives z.\n- Work up: put z into row 2 to find y, then y and z into row 1 to find x.\n- Check the answer in the first equations, not the stepped ones.\n\n**Rules of thumb:** Do to the constant whatever you do to the rest of the row. To keep whole numbers, multiply a row by a number other than 0 before you add. A determinant that is not 0 means exactly one answer. A determinant of 0 means none or many, and only the finished grid says which.\n\n**Worked example:** Three loops sit in a row. Each end loop has 3 Ω of its own, and the middle loop 6 Ω. Each pair of neighbours shares 3 Ω. 12 V drives loop 1 and 6 V drives loop 3. These are example figures. With all three loop currents drawn clockwise, going round each loop gives 6I₁ − 3I₂ = 12, −3I₁ + 12I₂ − 3I₃ = 0 and −3I₂ + 6I₃ = 6. Its determinant is 324, so there is exactly one answer. Double row 2 and add row 1: 21I₂ − 6I₃ = 12. Multiply row 3 by 7 and add the new row 2: 36I₃ = 54, so I₃ = 1.5 A. Then 21I₂ − 9 = 12, so I₂ = 1 A. Then 6I₁ − 3 = 12, so I₁ = 2.5 A. Check in row 2 of the first grid: −7.5 + 12 − 4.5 = 0. The resistor that loops 2 and 3 share carries I₂ − I₃ = −0.5 A. So 0.5 A flows through it against loop 2's arrow.\n\n**Common mistakes**\n- Leaving the constant column out of a move.\n- Putting a number in the wrong column when a letter is missing.\n- Clearing column 2 with row 1, which spoils the zero in column 1.\n- Reading 0 = 0 as no answer. On its own it means many answers.\n- Reading a zero determinant as no answer. It can mean many.\n- Checking only in the stepped grid. A slip in a move then goes unseen."
