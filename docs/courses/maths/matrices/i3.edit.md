   - After: Swap the order and the product usually changes.[^2] In BA the shear acts first. ... So BA = [0 −1; 1 1], a different move.

2. **Explain, row times column (the rule first, then why)**

   - After: You can work out the product without drawing. Each entry is a row of A times a column of B. B sends i to B's own column 1. ... Each number is a row of A times that column. You multiply matching pairs and add.

3. **whatAmILookingAt, screen 3 (one idea per sentence)**

   - After: 3, j follows too. B turns j to (−1, 0). A leaves it there, because the shear moves nothing on the across axis. The product's columns light up. They show where i ends, (1, 1), and where j ends, (−1, 0).
