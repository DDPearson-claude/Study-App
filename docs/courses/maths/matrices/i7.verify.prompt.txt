Notes (claims, and the sources that support them):
- Gauss elimination turns the equations into triangular form with the same solution, then solves by back-substitution. [R1]
- Row operations on a matrix include multiplying a row by a nonzero number and adding a nonzero multiple of one row to another. [R2][R3]
- Breaking a circuit into simple loops and applying Kirchhoff's law gives linear equations in the unknown currents. [R4]
- A set of equations may have a unique solution, infinitely many or none. [R5]
- In a matrix that holds a system of equations, each row of entries belongs to one equation. [R6]  (from an idea this one builds on)
- A matrix times a column of amounts gives a mix of the matrix's own columns, a linear combination. [R7]  (from an idea this one builds on)
- A move that squashes a plane onto a line has no inverse, because a line cannot be unsquished into a plane. [R8]  (from an idea this one builds on)
- A matrix is invertible if its determinant is not zero. [R9]  (from an idea this one builds on)
- A system AX = B is solved by multiplying both sides by the inverse of A. [R10]  (from an idea this one builds on)
- In mesh analysis, the loop currents are found with the inverse of the resistance matrix. [R11]  (from an idea this one builds on)
- A 3 by 3 determinant is the sum of each first-row element times its cofactor. [R12]  (from an idea this one builds on)
- The cross product is the determinant of a 3 by 3 matrix, an easier way to remember its components. [R13]  (from an idea this one builds on)
- Symmetrical components split an unbalanced set of three phasors into three balanced sets. [R14]  (from an idea this one builds on)
- Matrix methods turn the loop equations of a circuit into one equation, [V] = [R] x [I], that a solver can handle together. [R11][R4]  (whole topic)
