    "text": "The inverse of a matrix A is the move that plays A backwards. It is written A⁻¹. Do A, then A⁻¹, and every point is back where it started. A move has an inverse only when it does not squash the plane flat. That is when its determinant is not zero.\n\nUndoing means knowing where each point came from. Take A = [3 1; 4 2]. It sends (1, 1) to (4, 6), because 1 lot of (3, 4) plus 1 lot of (1, 2) is (4, 6). So A⁻¹ must send (4, 6) back to (1, 1), and every other point back too. A then A⁻¹ leaves every point alone. So A⁻¹A is the identity matrix I, the do-nothing move. Done the other way round, AA⁻¹ is I too. The little −1 means undo, as it did for an inverse function. It does not mean 1 ÷ each entry.\n\nHere is how to find it. Swap a and d, and change the signs of b and c. For A that gives [2 −1; −4 3]. Multiply it by A and you get [2 0; 0 2]. That is 2 times I, and 2 is A's determinant, 3 × 2 − 1 × 4. The same happens for any matrix. [d −b; −c a] times [a b; c d] is (ad − bc) times I. So divide the swapped matrix by the determinant, and you have the [[inverse]]. For A it is [1 −0.5; −2 1.5]. Multiply back to check that A⁻¹A gives I.\n\nThe recipe divides by the determinant, so it fails when that is 0. The picture shows why. Lean j towards i's line and the determinant shrinks. The inverse's entries grow, and the point that lands on a fixed dot races away. At 0 the whole plane lies on one line. A dot off that line is hit by no point. A dot on it is hit by a whole line of points, so nothing can say which one you started from. You cannot unsquish a line back into a plane.[^1] So a matrix with determinant 0 has no inverse. Textbooks call it [[singular]]. A matrix whose determinant is not zero is [[invertible]].[^2]\n\nThat is what solves a pair of equations. Write 3x + y = 4 and 4x + 2y = 6 as AX = B. Here X is the column (x, y) and B is (4, 6). The unknowns are the point A carried onto (4, 6). So multiply both sides on the left by A⁻¹.[^3] That gives X = A⁻¹B = (1, 1). A⁻¹ goes on the left, because order matters with matrices. A two-loop circuit works the same way. Its resistance grid times its loop currents gives its loop voltages.[^4] So the currents are the inverse grid times the voltages.\n\n**The inverse A⁻¹ plays a move backwards, so A⁻¹A = I and AX = B gives X = A⁻¹B. It exists only when the determinant is not zero.**"
