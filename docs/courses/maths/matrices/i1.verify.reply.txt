Each number in it is an [[entry]], named by its row first, then its column. On one line, a grid is written row by row with a semicolon between rows. In [4 7 1; 2 5 3], row 2, column 1 is 2, while row 1, column 2 is 7. Now take the equations x + 3y = 7 and 2x + y = 4. Their numbers make the grid [1 3; 2 1], one row for each equation. The grid times (x, y) is therefore x lots of column 1 plus y lots of column 2, laid nose to tail.
