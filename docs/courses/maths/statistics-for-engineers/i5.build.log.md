## Version of the shared language
The three "Copy this code" blocks of dataviz.md (fifth version) are pasted unchanged. A script spliced them into a template and checked they match the source exactly (scratchpad i5/splice.mjs). The structure follows i4:
- STEPS, with one compact stepper.
- B.motion for the clocks and stories.
- The prototype's lifetimes engine, ported: the clock on M.Tl, B.fall as the hand passes a unit's lifetime, the upper row dropping onto the lower, and hollow units held in a parallel pair.
- Stills for the read-through (stillAt).
- drawnAt for the checks. It puts back every spring, unit and clock state.
