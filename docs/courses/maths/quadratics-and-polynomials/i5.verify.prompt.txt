It is lesson 4's completing the square done once with letters, so you need not do it each time, and it reads as a centre, −b ÷ 2a, with the two roots the same distance either side.\n\nHere is where it comes from. a is not 0, or there would be no x² and no quadratic. Take a out of the x² and x terms: a(x² + (b ÷ a)x) + c. Half of b ÷ a is b ÷ 2a, so the corner is (b ÷ 2a)², and it comes off a times, which is b² ÷ 4a. That gives a(x + b ÷ 2a)² + c − b² ÷ 4a.[^2] Set it to 0 and take the plain part across: a(x + b ÷ 2a)² = b² ÷ 4a − c, and since c is 4ac ÷ 4a, that is (b² − 4ac) ÷ 4a. Divide both sides by a: (x + b ÷ 2a)² = (b² − 4ac) ÷ 4a². A number squared makes this when it is the square root either way, so x + b ÷ 2a = ±√(b² − 4ac) ÷ 2a (√(4a²) is 2a or −2a, and the ± covers both). Take b ÷ 2a across: x = (−b ± √(b² − 4ac)) ÷ 2a. Check it on lesson 4's x² + 6x + 2 = 0: a = 1, b = 6, c = 2, so b² − 4ac = 36 − 8 = 28, and √28 = √4 × √7 = 2√7, as in Powers and roots.
