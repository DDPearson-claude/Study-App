    "text": "The [[quadratic formula]] gives the answers to any quadratic equation ax² + bx + c = 0 that has them: x = (−b ± √(b² − 4ac)) ÷ 2a.[^1] It is lesson 4's completing the square done once with letters, so you never have to do it again, and it reads as a centre, −b ÷ 2a, with the two roots the same distance either side.\n\nHere is where it comes from. a is not 0, or there would be no x² and no quadratic. Take a out of the x² and x terms: a(x² + (b ÷ a)x) + c. Half of b ÷ a is b ÷ 2a, so the corner is (b ÷ 2a)², and it comes off a times, which is b² ÷ 4a. That gives a(x + b ÷ 2a)² + c − b² ÷ 4a.[^2] Set it to 0 and take the plain part across: a(x + b ÷ 2a)² = b² ÷ 4a − c, which over one bottom number is (b² − 4ac) ÷ 4a. Divide both sides by a: (x + b ÷ 2a)² = (b² − 4ac) ÷ 4a². A number squared makes this when it is the square root either way, so x + b ÷ 2a = ±√(b² − 4ac) ÷ 2a (√(4a²) is 2a or −2a, and the ± covers both). Take b ÷ 2a across: x = (−b ± √(b² − 4ac)) ÷ 2a. Check it on lesson 4's x² + 6x + 2 = 0: a = 1, b = 6, c = 2, so b² − 4ac = 36 − 8 = 28, and √28 = √4 × √7 = 2√7, as in Powers and roots. So x = (−6 ± 2√7) ÷ 2 = −3 ± √7, about −0.35 or −5.65, the same as before. The ± is two answers: drop it and you lose a root.\n\nSplit the formula and it is a picture: x = −b ÷ 2a ± √(b² − 4ac) ÷ 2a. The first part is the centre, the line of symmetry from lesson 4, halfway between the roots. The second is the spread, the same distance out to each root, which the two arrows show. Everything rests on b² − 4ac, the number under the square root, called the [[discriminant]].[^3] Drag y = x² + 6x + c up by raising c and the discriminant, 36 − 4c, falls, so the arrows shrink. At c = 9 it is 0: the arrows have no length, the two roots meet at x = −3, and the curve just touches the axis. That is one [[repeated root]], because x² + 6x + 9 is the perfect square (x + 3)², so both brackets give −3. Lift it to c = 11 and the discriminant is −8. No number on the number line squares to a negative, so there is nothing to take the square root of and the curve never reaches the axis.\n\n**x = (−b ± √(b² − 4ac)) ÷ 2a, and b² − 4ac tells you before you start whether there are two roots, one repeated root or no real roots.[^3]**"

The two roots must average to −b ÷ 2a, which is a quick check.\n\n**Worked example:** Lesson 4 found −x² + 4x + 10 = −(x − 2)² + 14. Solve −x² + 4x + 10 = 0 with the formula: a = −1, b = 4, c = 10. b² − 4ac = 16 − 4 × (−1) × 10 = 16 + 40 = 56, positive, so two roots. √56 = 2√14, about 7.48. x = (−4 ± 7.48) ÷ (−2), so x is about −1.74 or 5.74. They average to 2, which is −b ÷ 2a = −4 ÷ −2, the highest point lesson 4 found.
