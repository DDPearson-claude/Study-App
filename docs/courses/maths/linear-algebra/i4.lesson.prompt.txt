Research notes (claims, and the sources that support them):
- The column space is all combinations of the columns of A, and the null space is all solutions x of Ax = 0. [1][2]
- The rank of A is the number of independent columns, which equals the number of independent rows. [3]
- If b is not in the column space of A, Ax = b has no solution; if the null space holds more than the zero arrow, a solution that exists is not alone. [4][5]
- When rank(A) is less than the number of unknowns n and a solution exists, the solutions form a shifted copy of the null space of dimension n minus the rank. [6]
- The span of a pair of arrows is every arrow reachable by scaling and adding them; most pairs in 2D reach the whole plane, but arrows lying along one line reach only that line. [7]  (from an idea this one builds on)
- A third arrow lying in the span of the first two adds no new arrows to the span, so it is not independent of them. [8]  (from an idea this one builds on)
- A basis of a space is a set of linearly independent arrows that span that space. [9]  (from an idea this one builds on)
- A line needs an arrow from the origin to a point on it and an arrow parallel to it; a plane has a normal arrow perpendicular to it. [10][11]  (from an idea this one builds on)
- A rotating laser's receiver shows by its arrows whether it is above or below the beam, and digital-readout models show how far from on-grade it is (i3 analogy). [12]  (from an idea this one builds on)
- A basis is a set of independent arrows that span the space, and any numbers describing an arrow depend on the basis chosen. [9][13]  (whole topic)
