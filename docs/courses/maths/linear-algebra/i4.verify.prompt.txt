Notes (claims, and the sources that support them):
- The column space is all combinations of the columns of A, and the null space is all solutions x of Ax = 0. [R1][R2]
- The rank of A is the number of independent columns, which equals the number of independent rows. [R3]
- If b is not in the column space of A, Ax = b has no solution; if the null space holds more than the zero arrow, a solution that exists is not alone. [R4][R5]
- When rank(A) is less than the number of unknowns n and a solution exists, the solutions form a shifted copy of the null space of dimension n minus the rank. [R6]
- The span of a pair of arrows is every arrow reachable by scaling and adding them; most pairs in 2D reach the whole plane, but arrows lying along one line reach only that line. [R7]  (from an idea this one builds on)
- A third arrow lying in the span of the first two adds no new arrows to the span, so it is not independent of them. [R8]  (from an idea this one builds on)
- A basis of a space is a set of linearly independent arrows that span that space. [R9]  (from an idea this one builds on)
