    "text": "Multiplying by −1 turns a number's arrow half way round, so a quarter turn done twice does the same job as multiplying by −1. That quarter turn is a new number, j, and j × j = −1. Here is why a new number is needed. On the number line no number squares to a negative: 3 × 3 = 9, and as in Negative numbers, −3 × −3 = 9 too, while 0 × 0 = 0. So x² = −9 has no answer on the line, and in Quadratics x² + 2x + 5 = 0 had no real roots.\n\nDraw each number as an arrow from 0. Multiplying by −1 keeps the arrow's length and points it the other way, so 3 becomes −3: the arrow is turned through 180 degrees, a half turn.[^1] On the line a half turn and a mirror at 0 land in the same place, but a turn can be done in two equal halves, and that half is what we are looking for. Multiply by −1 twice and the arrow makes a full turn, 360°, back where it started, which is why −1 × −1 = 1. Now look for a number that, multiplied in twice, does what −1 does. Its turn done twice must make 180°, so it is 90°, a quarter turn. It leaves the arrow from 1 pointing straight up, off the line, and no number on the line could do that, since none squares to a negative. So it is a new number, called [[j]]. Multiplying by j turns an arrow through +90 degrees, a quarter turn anticlockwise,[^2] and two quarter turns make a half turn, so j × j = −1.[^3] Engineers write j because i already means electric current.[^4] Maths books write i for the same number.\n\nKeep tapping × j and the arrow goes round: 1, j, −1, −j, 1. That gives the powers of j from the rule, with no new facts: j² = −1, j³ = j² × j = −j, and j⁴ = j² × j² = −1 × −1 = 1, so the powers repeat every four. Stretch the arrow to 3 first and (j3)² = j × j × 3 × 3 = −9, so j3 answers x² = −9. So does −j3, three quarter turns twice, since (−j3)² = −1 × −1 × j × j × 9 = −9. Many books, mathcentre among them, start the other way: j stands for the square root of −1, and j² = −1 follows.[^3] This lesson leads with j × j = −1, because two numbers, j and −j, square to −1, and because the usual rule √a × √b = √(ab) breaks for negatives. Read √−4 as j2 and √−9 as j3: the rule would give √36 = 6, but j2 × j3 = j × j × 6 = −6. Back to the quadratic: b² − 4ac = 4 − 20 = −16, which is (j4)², so x = (−2 ± j4) ÷ 2 = −1 ± j2.
