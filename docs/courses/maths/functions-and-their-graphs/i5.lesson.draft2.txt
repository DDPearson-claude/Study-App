    "text": "Shifting a graph slides it without changing its shape. Add a number to the output and the graph slides up or down; change the input inside the bracket and it slides left or right. The sideways move is the one that catches people out, and the function machine from lesson 1 shows why it goes the way it does.\n\nf(x) + 2 means put x through the machine, then add 2 to what comes out. Take the square from lesson 3, f(x) = x². At x = 2 it gives 4, so x² + 2 gives 6. The input is the same and only its output is 2 higher, and that is true at every input, so every point rises 2 and the whole graph slides up 2. That is a [[vertical shift]], a slide straight up or down,[^1] and x² − 3 slides down 3 in the same way. You have met one before. The transmitter's rule from lesson 2, S(p) = 0.16p + 4, is a straight-line rule of the kind instruments use,[^5] and it is the line 0.16p lifted by its 4 mA, so the 8 mA that line gives at 50% becomes 12 mA. Sliding up changes no steepness, so the slope is still 0.16 mA per percent.\n\nf(x − 3) means take 3 off the input first, then put what is left through the machine. So (x − 3)² gives 0 only when x − 3 is 0, which is at x = 3, not at 0. To get the old output 1 you now feed in 4, not 1, and to get 4 you feed in 5, not 2. Each input must be 3 bigger to give the old output, so every point sits 3 further right, and the graph slides 3 to the right. That is a [[horizontal shift]], a slide along the x-axis.[^2] In the same way f(x + 2) adds 2 before the machine, so each input can be 2 smaller, and the graph slides 2 to the left. A common slip is to move f(x + 3) to the right because the 3 is positive.[^3] One point settles it: find the input that makes the bracket 0. Everything about the graph slides with it, including where the machine starts: √x starts at 0, so √(x − 4) starts at 4. The two moves do not get in each other's way, so (x − 3)² + 2 slides right 3 and up 2, and its bottom moves from (0, 0) to (3, 2).\n\n**Adding outside the bracket, f(x) + 3, slides the graph up 3;[^1] changing the input inside, f(x − 3), slides it 3 to the right, because each input must be 3 bigger to give the old output.**"

    "text": "- Up or down: look outside the bracket. f(x) + 3 slides the graph up 3, and f(x) − 3 slides it down 3.\n- Left or right: look inside the bracket and find the input that makes it 0. The point that sat at input 0 now sits there. f(x − 3) slides right 3, and f(x + 3) slides left 3.\n- Move one easy point, such as the bottom of a U, then the others: every point moves the same way by the same amount.\n- Check one moved point in the new rule.\n\n**Rule of thumb:** Outside the bracket moves it up or down, the way the sign says. Inside moves it sideways, the opposite way to the sign: a minus moves it right and a plus moves it left.\n\n**Worked example:** Sketch y = (x − 3)² + 2 from y = x². Inside, x − 3 is 0 at x = 3, so the graph slides 3 to the right. Outside, the + 2 slides it up 2. The bottom (0, 0) moves to (3, 2), and the points (1, 1) and (2, 4) move to (4, 3) and (5, 6). Check one: at x = 5, (5 − 3)² + 2 = 4 + 2 = 6.\n\n**Common mistakes**\n- Moving f(x + 3) to the right because the 3 is positive.[^3] The bracket is 0 at x = −3, so the graph moves left.\n- Mixing up outside and inside. x² − 3 drops the graph 3; (x − 3)² slides it 3 to the right.\n- Forgetting that where the machine starts slides too. √(x − 4) starts at x = 4, not 0."
