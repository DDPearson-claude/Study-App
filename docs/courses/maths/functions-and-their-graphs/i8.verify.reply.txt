That works only for a function that never gives two inputs the same output.\n\nTake lesson 1's machine, × 3 then − 1. Put in 5: × 3 gives 15, then − 1 gives 14. To get back, undo the last step first. + 1 turns 14 into 15, and ÷ 3 turns 15 into 5. So the inverse of multiplying by 3 and subtracting 1 is adding 1 and then dividing by 3.[^2] The order matters because each step worked on what the step before handed it, as in lesson 7's chains. Take \"add 4, then double\": 3 becomes 7, then 14. Halve and then take 4, and 14 goes back to 7 and then 3. Take 4 and then halve, and 14 gives 10 and then 5, the wrong start. The 4 went in before the doubling, so it has to come off after the halving. Textbooks call the undoing machine the [[inverse function]], write it f⁻¹(x) and read it \"f inverse\". They add that the −1 is part of the name, not a power, so f⁻¹(x) is not 1 ÷ f(x). Feeding f's output straight into f⁻¹ is a chain, f⁻¹(f(x)), and it gives back x.\n\nSome machines cannot be undone. The square sends 3 and −3 to the same 9. The root machine gets only the 9, nothing in it says which went in, and it hands back 3, the positive root. Only one-to-one functions have an inverse,[^3] and a level line that cuts a graph twice shows two inputs giving the same output.[^4] The way round it is a lock: take only inputs of 0 and up, and each output comes from one input again, so the root undoes the square every time. Rearranging P = I²R into I = √(P ÷ R), as you did in Solving equations, is exactly this, ÷ R and then the root, with the current taken as a size, 0 and up. Textbooks add that drawn on one grid, the graph of f⁻¹ is the graph of f mirrored in the line y = x, because every point swaps its two numbers: (5, 14) on f becomes (14, 5). The SQA HN engineering maths unit asks you to find inverse functions and to graph them.[^5]\n\nWhen the controller takes the square root, as it can instead of the transmitter, it runs two of this course's machines backwards. Flow fractions run from 0 to 1, so the square law is already locked, and the root undoes it: 50% pressure difference is 71% flow.[^7][^1] **An inverse function, f⁻¹, does the opposite of each step in reverse order and hands back the input, and only a function that never gives two inputs the same output has one.[^3]**"
