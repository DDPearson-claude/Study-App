Swap them round and the same input usually gives a different output.\n\nTake g, which adds 4, and f, which doubles. Put 3 into g and 7 comes out. That 7 is f's input, so 14 drops out. Two machines that both only add, or both only multiply, give the same either way, so a swap usually changes the answer, but not always.
