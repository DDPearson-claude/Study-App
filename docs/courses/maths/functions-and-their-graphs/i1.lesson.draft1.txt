    "text": "A function is a machine with a rule inside. You put a number in, and the rule gives back exactly one number.[^1] Take the machine whose rule is × 3, then − 1. Drop in 5. The first step makes 15, the second makes 14, and 14 drops out. The number you put in is the [[input]] and the number that comes out is the [[output]]. A rule that gives exactly one output for each input is called a [[function]].[^1]\n\nTextbooks add that a function is given a one-letter name, usually f, and that f(5), read \"f of 5\", stands for the output when 5 goes in. So for this machine f(5) = 14. The bracket holds the input. It does not mean f times 5, because f is the name of a machine, not a number. The whole rule is written f(x) = 3x − 1, where x stands for any input. Whatever goes in the bracket replaces x, all of it at once. So f(−2) = 3 × (−2) − 1 = −7, and f(a + 1) = 3(a + 1) − 1 = 3a + 2. Other letters name functions too. P(I) = I²R is the power P for a current I, so with a 2 Ω resistor P(3) = 18 W.\n\nEach input and its output make a pair. Written down, the pairs make a table, and plotted with the input along the bottom and the output up the side, they make dots on a graph. For f(x) = 3x − 1 the dots sit on one straight line, and an input in between, such as 0.5, lands on the same line. The machine, the table and the graph are three ways of showing one function. A function does not need a formula. A log of a pump's current, one reading for each hour, is a function. A machine that gives 3 whatever goes in is a function too. But the rule \"a number that squares to make it\" gives both 4 and −4 for 16, so it is not a function.\n\nThe flow meter in the course's puzzle is a machine like this, with a pressure difference going in and a current coming out, 12 mA for 50% of its full pressure difference.[^3]\n\n**A function is a rule that gives exactly one output for each input,[^1] and f(5), read \"f of 5\", is the output when 5 goes in.**"

    "text": "- Write out the rule with a bracket wherever x appears, so f( ) = 3( ) − 1.\n- Put the whole input into each bracket, a number or an expression such as a + 1.\n- Work it out in the order the rule says.\n- To check that a rule or a table is a function, ask of each input whether it gives exactly one output. A formula is not needed, and two inputs sharing an output is fine.\n\n**Rule of thumb:** Say f(5) aloud as \"f of 5\", the output when 5 goes in. The bracket holds the input and never means times.\n\n**Worked example:** A transmitter on a 4 to 20 mA loop turns a reading, as a percentage of full scale, into a current. Textbooks add that 0% sends 4 mA and 100% sends 20 mA. Instrument scaling uses a straight-line rule, y = mx + b,[^2] so here S(p) = 0.16p + 4. The 16 mA between 4 and 20 is spread over 100%, which is 0.16 mA for each percent. For 25%, S(25) = 0.16 × 25 + 4 = 4 + 4 = 8 mA. Check the ends: S(0) = 4 and S(100) = 16 + 4 = 20.\n\n**Common mistakes**\n- Reading f(x) as f times x. f is the machine's name, so f(a + 1) is not fa + f.\n- Putting in only part of an expression, so f(a + 1) becomes 3a + 1 − 1 = 3a. The whole of a + 1 is multiplied, giving 3a + 2. Check with a = 2: 8, not 6.\n- Doing the steps out of order, so f(2) becomes (2 − 1) × 3 = 3 instead of 3 × 2 − 1 = 5.\n- Thinking a function must have a formula, or an output that changes. A table of readings and a machine that always gives 3 are both functions."
