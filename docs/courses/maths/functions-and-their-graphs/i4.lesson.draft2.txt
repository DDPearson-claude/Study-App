  "explain": {
    "text": "A function's [[domain]] is every input it takes, and its [[range]] is every output it gives for those inputs.[^1] On a graph you can see both as shadows. The graph's shadow straight down onto the input axis covers its domain, and its shadow straight across onto the output axis covers its range. Take the transmitter from lesson 2, S(p) = 0.16p + 4, a straight-line rule of the kind instruments use.[^7] It takes 0% to 100% of its scale, so its domain is 0 to 100%. S(0) = 4 and S(100) = 0.16 × 100 + 4 = 20, and the line climbs steadily in between, so its range is 4 to 20 mA.\n\nTwo things limit a domain. The situation can: a level reading runs only from 0% to 100% of its scale. And the rule can. When nothing else limits it, the domain is every real input that does not ask for an operation with no answer, such as dividing by zero or taking the square root of a negative number.[^2] On y = 1/x, the input 0 would mean 1 ÷ 0, and no number times 0 gives 1, so 0 has no output. Its domain is every number but 0. Near 0 the curve climbs ever closer to the up axis without touching it, and textbooks call a line that a curve creeps ever closer to like this an [[asymptote]]. On y = √x, a negative input would need a number that gives a negative when multiplied by itself. A positive times a positive is positive, and so is a negative times a negative, so no ordinary number does it. Its domain is 0 and up, and 0 itself is in, because √0 = 0.\n\nThe range takes more care, because its ends need not come from the domain's ends. A number times itself is never negative, so y = x² never gives an output below 0. Set its inputs from −2 to 3 and the ends give 4 and 9, but the curve dips to 0 at x = 0 on the way, so the range is 0 to 9, not 4 to 9. On y = 1/x, 1 divided by any number is never 0, so the range has a hole at 0, just as the domain does, and the curve creeps ever closer to the bottom axis too. The square root's shadows show why the flow meter in this course's puzzle reads as it does. With pressure difference and flow as fractions of full, the flow is the square root of the pressure difference,[^11] so both bands run 0 to 1, but they are not spread alike. 12 mA, the 50% point of the 4 to 20 mA scale, is 50% of the pressure difference but 71% of the flow, because √0.5 = 0.707.[^3]\n\n**The domain is every input a function takes, read along the input axis, limited by the situation and by any input the rule has no answer for; the range is every output it gives for those inputs, read up the output axis from everything the graph reaches, not just its ends.**"

  "practice": {
    "text": "- Start with the domain. Ask what the situation allows, such as 0% to 100% of a scale.\n- Then ask what the rule refuses: an input that would mean dividing by zero, or the square root of a negative number.\n- Now the range. Put the domain's ends through the rule.\n- Look along the graph for a lowest or highest point in between, such as the bottom of a U, and for any output the rule can never give, such as 0 from a one-over.\n- Read the domain along the input axis and the range up the output axis, never the other way round.\n\n**Rule of thumb:** The domain comes from what goes in, so start there. Slow down for the range: a graph's ends do not always give its lowest and highest outputs.\n\n**Worked example:** A 12 V supply feeds a resistance that can be set from 3 Ω to 12 Ω, so the current is I = 12/R. The domain is 3 to 12 Ω, which does not include 0, so nothing is divided by zero. At 3 Ω the current is 12 ÷ 3 = 4 A, and at 12 Ω it is 12 ÷ 12 = 1 A. The one-over falls steadily between them with no turning point, so the range is 1 to 4 A. The biggest resistance gives the smallest current, so the range's ends come from the domain's ends the other way round.\n\n**Common mistakes**\n- Swapping the two. The domain is inputs, along the bottom; the range is outputs, up the side.\n- Reading the range from the ends alone. y = x² on −2 to 3 gives 4 and 9 at its ends but reaches 0 in the middle, so its range is 0 to 9.\n- Taking the height where a graph meets the output axis as its domain. That height is an output.\n- Thinking √x refuses 0. √0 = 0, so 0 is in its domain; only negative inputs are refused."
